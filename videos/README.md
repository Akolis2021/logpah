# LOGPAH Video Directory

Place your video files in this folder (or subfolders) to display them on the website.

### Supported Formats
- MP4 (`.mp4`) — recommended for maximum browser compatibility (H.264 video codec, AAC audio).
- WebM (`.webm`)

### Suggested File Names
- `8th-anniversary.mp4` — 8th Anniversary celebration at Bariga
- `1st-anniversary.mp4` — 1st Anniversary celebration
- `hygiene-session.mp4` — Good Hygiene educational session at Ayangburen Primary School (Mrs. Oluwabunmi Adenuga)
- `elderly-care.mp4` — Visit to MASC Care Home, Abule Egba
- `ketu-feeding.mp4` — Feeding outreach at Ketu bus stop
- `empowerment.mp4` — Women and girls empowerment outreach

### YouTube / Vimeo Embeds
If you prefer not to host large video files locally, you can paste the YouTube or Vimeo video link directly into the `data-video-url` attribute in `gallery.html`.
